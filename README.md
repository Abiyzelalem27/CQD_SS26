


# 📌 Overview

This repository contains the weekly programming exercises for the course “Computational Quantum Dynamics” (Summer Semester 2026).

- Quantum mechanics  
- Linear algebra  
- Numerical analysis    
  

# 📚  Overview

## Quantum Mechanics Basics and Numerical Discretization

- Schrödinger equation 
- Harmonic oscillator  

## Numerical Linear Algebra for Quantum Systems

- QR algorithm for eigenvalue problems  
- Sparse matrix formats (COO, CSR, DIA)  
- Krylov subspaces and matrix power methods  
- Lanczos algorithm for sparse Hamiltonians  


##  Split-Step Fourier Method

- Trotter and Strang decomposition  
- Fourier transform  
- FFT algorithm 
- Cooley–Tukey method  

## Many-Body Quantum Systems and Approximations

- Variational principle for ground states  
- Mean-field approximation   
- Gross–Pitaevskii equation  



## Spin-½ Systems and Collective Quantum Physics

- Pauli matrices 
- Collective spin operators  
- Lipkin–Meshkov–Glick (LMG) model  

## Ground State Search with Variational Monte Carlo

- Variational Monte Carlo approximates 
- Jastrow ansatz and Neural Quantum States 
- Monte Carlo sampling and local energy 

## Open Quantum Systems and Monte Carlo Wave Functions

- Lindblad master equation
- Compare Monte Carlo Wave Function simulations with direct master equation
